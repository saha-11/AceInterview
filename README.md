# AceInterview

AceInterview is a modern interview preparation platform built using HTML, CSS, JavaScript, and Firebase.

## Features

- Google Authentication
- Firebase Firestore
- Company-wise interview preparation
- Technical Questions
- HR Questions
- Coding Problems
- Interview Tips
- Random Practice Session Generator
- Progress Tracking
- Export & Print Support
- Responsive Premium UI

## Technologies

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Firebase Authentication
- Firestore Database
